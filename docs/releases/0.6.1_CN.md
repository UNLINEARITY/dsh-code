# dsh-code 发布说明 - 0.6.1

## 概览

0.6.1 是缺陷修复版本：修复延迟会话在首次输入时出现的鬼影重复渲染，并让全局 `deepseek`/`dsh-code` 别名在 cli profile 尚未挂载 dsh-code 时明确报错退出，而不是挂起。

## 修复

### 首次输入渲染

- 裸启动现在会在占位树以真实会话 id 重挂载前清屏。此前旧的 static 头部残留在屏幕上，与新的头部叠加，直到 resize 重放才会消失——表现为双鲸鱼头。
- 排队提示行改为在 live 区域渲染，不再刷入 append-only 转录区。inbox 之后可能将其退役，而 append-only 刷新无法擦除已退役的行——此前第一条消息会渲染两行（排队行 + 落地行），直到 resize。
- 双鲸鱼头与首条消息重复均由 App 级 TTY 回归测试覆盖：断言清屏重挂载后物理屏幕内容恰好为一个头部、一条消息。

### 启动器

- `deepseek` / `dsh-code` 启动前会检查 cli profile manifest：未挂载 dsh-code 时打印缺失的安装步骤并以退出码 1 结束，不再启动一个没有 TUI runner、挂起进程的裸 profile。
- 启动器的 DSH 缺失提示不再引用 `@next` dist-tag。

## 测试

- 192 个测试全部通过（`pnpm test`），包含启动器预检与两种首次输入鬼影模式的新回归覆盖。

## 重要说明

- 从 0.6.0 升级无需迁移配置或持久会话。
- 运行时要求保持 Node `^22.19 || >=24` 与兼容的 `@deepseek-ai/dsh` 安装。
