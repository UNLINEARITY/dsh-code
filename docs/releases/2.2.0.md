# DSH-Code 2.2.0

English | [中文](https://github.com/UNLINEARITY/dsh-code/blob/2.2.0/docs/releases/2.2.0_CN.md)

DSH-Code 2.2.0 supports DeepSeek Harness `0.2.2-rc.5`. It reuses the runtime packages installed with dsh, reducing duplicate downloads when installing the terminal bundle.

## Models and subagents

- Each session saves its model and reasoning effort. Resume the session to continue with those choices, including a model selected before sending the first prompt.
- A subagent uses the model selected for it from its first request. If you leave the subagent model unset, it uses the parent session’s model.
- The `standard`, `cordis`, and `ptc` presets remove `interrupt_agent` from the model’s default tool list. You can interrupt a subagent from `/agents`.

## Install or upgrade

Use Node.js 24.9.0 or later. Close running `dsh` and `deepseek` sessions before installing the matching versions.

```sh
npm install -g --allow-scripts=@deepseek-ai/dsh-subprocess-local,koffi,node-pty,@google/genai,protobufjs @deepseek-ai/dsh@0.2.2-rc.5 pnpm
npm install -g dsh-code@2.2.0
deepseek setup
```

Run `deepseek` to open the terminal interface. If your profile includes separately installed Harness plugins, update them to `0.2.2-rc.5`. You can remove a separate installation of `@deepseek-ai/dsh-tool-session-query` because dsh supplies it.

For profiles linked to a source checkout and help with installation errors, see the [installation and upgrade guide](https://github.com/UNLINEARITY/dsh-code/blob/2.2.0/docs/installation.md).
