# dsh-code Release Notes - 1.0.2

## Overview

Version 1.0.2 is a terminal interaction and rendering refinement release. It makes multiline editing dependable under rapid input, brings reasoning and tool output under one coherent fold, and improves the responsiveness of workspace references without changing the underlying Harness session model.

## Major improvements

### Composer and editor behavior

- The composer now maintains one authoritative caret across wrapped and multiline drafts, preventing duplicate or misplaced cursors during movement, editing, animation, and resize.
- Word navigation and deletion respect the current word fragment and Unicode grapheme boundaries, including CJK text; logical-line Home, End, kill, and yank operations follow the same editor model.
- Batched Home, End, Delete, and Backspace input is processed in order, and Kitty CSI-u key sequences are normalized before Ink handles the input.
- Cursor visibility is restored after edits and movement. Asynchronous image inspection and submission are cancellable without losing the draft, attachments, or cursor position.

### Transcript, reasoning, and tool output

- Ctrl+R now controls reasoning and tool-detail visibility as one fold state across live output and settled transcript rows.
- Tool cards display at most three rows by default, with a compact indicator when additional output is hidden; Ctrl+O remains the full-detail view for a selected entry.
- Streaming, settled, and replayed reasoning continue to share the same source-backed representation, while live updates remain bounded during a turn.
- `Deep diving...` uses a slower two-second blue shimmer with a continuously breathing leading `✻`; the busy composer indicator retains the original eight-frame braille chase.

### Workspace references

- Path-oriented queries such as `@src/` skip unrelated session discovery while navigating workspace directories.
- Mention lookups are lightly debounced, keep current candidates visible while a new query settles, and reject responses from superseded queries.
- Bare `@` queries continue to support both workspace files and session references, with existing insertion and directory-navigation behavior preserved.

## Bug fixes

### Fast terminal input

- Completion acceptance followed immediately by additional text now uses the latest draft and cursor state, preventing lost characters and stale menu state.
- Bracketed paste markers and editor-only control sequences no longer leak into the draft when input arrives as a combined terminal chunk.
- Terminal protocol cleanup remains paired with the TUI lifecycle so interrupted or completed sessions do not leave keyboard modes enabled.

## Compatibility and upgrade notes

- dsh-code 1.0.2 requires `@deepseek-ai/dsh@0.1.1-rc.2`; the Harness dependency line remains pinned to that release.
- Existing sessions require no migration.
- On release day, pnpm users should install the exact package version `dsh-code@1.0.2`; npm installation is not affected by pnpm's 24-hour release delay.
