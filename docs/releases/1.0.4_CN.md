# dsh-code 发布说明 - 1.0.4

## 概述

1.0.4 是迄今最大规模的稳定性发布，并围绕真实端点发现重建了供应商管理。审批后偶发的键盘死锁从根源消除：终端在所有界面切换间保持 raw 模式，丢失的粘贴结束标记不再滞留后续按键，转录滚动区也不会再被中断的重试或命令行永久冻结。供应商阶段现在打开一个统一配置页——API key、端点与模型列表同屏——附带发现阶段直连真实端点查询实际提供哪些模型，网关新增模型即刻可用。推理档位映射新增行内编辑器与模型间复制，供应商列表将已配置条目以品牌强调色分组置顶，Ctrl+C 可从任意阶段退出整个 /model 流程。

## 新功能

### 统一供应商配置页

- 供应商阶段取代了隐蔽的 Tab 深层菜单与独立密钥面板，合并为一页：API key（掩码输入、凭据状态内联显示）、端点 URL（留空即官方默认）、以及逐模型的上下文与输出窗口配置全部同屏。上下箭头在三个区域间移动；左右箭头在选中模型的上下文与输出字段间切换；数字编辑当前字段；末行接受手填模型 id；Enter 将 key、端点与模型一次保存。

### 真实端点模型发现

- 在配置页按 Tab 进入发现阶段，经与 Web Models 页相同的模型发现管道直连端点。手输 key 强制以草稿模式直连该 URL；key 为空时使用已存凭据。填了 URL 就绝不携带路由 id，官方内置目录不再遮蔽网关真实清单——探测始终到达 URL 字段所填的端点。
- 结果渲染为可勾选列表：已配置条目显示校验标记但不可重选，Enter 仅采纳勾选子集——选择性导入而非批量。端点披露时附带名称、上下文窗口与输出上限；f 重新拉取，Esc 返回。

### 推理档位编辑器

- 模型行现在直接内联编辑推理档位声明。按 e 将选中行转为编辑器，接受紧凑的「档位:wire」语法——以空格分隔的键值对如 low:low high:high max:max，其中 off:null 表示该档位不发送推理参数，单独的 false 表示禁用档位选择器，留空提交则恢复从已安装目录继承。Ctrl+U 清空草稿，Esc 取消编辑，未知或重复的档位名在写入前即被单行可操作提示拒绝。
- 按 c 打开选择页，列出所有已声明映射的模型——settings 声明逐字复制以保留各方言的 wire 拼写，目录广播等级按恒等映射提供——新增模型一次按键即可采纳经过验证的映射，声明写入后由后台能力同步自动传播到其它路由。
- 行标签以 eff:N（已声明档位数）、eff:off（显式禁用）、eff:~（继承中）呈现当前状态。

## 修复

### 审批键盘死锁

- 终端在 composer 与审批条每次交接时短暂退出 raw 模式，将按键滞留在行缓冲直到下一次 Enter。终端现在在整个应用生命周期内保持 raw 模式，从根源消除死锁。
- 未终止的括号粘贴（终端缺陷或粘贴中崩溃）无超时无逃生地滞留后续全部按键。滞留字节现在在共享一秒窗口后放出，Esc 与 Ctrl+C 始终可达。
- 在 /mode 空列表上按 Enter 因未捕获 TypeError 使进程崩溃。存在性检查现在与所有其他面板一致。
- 转录滚动区在重试或命令被中断时可能永久冻结：持续 running 的行阻塞了 settled 历史与动态视口的分界。turn-end 折叠现在终态化任何被中断的行使边界始终前进。
- 审批挂起期间 Ctrl+C 被静默吞掉；现在中断运行中的回合并撤回问题。

### 终端高度与宽度预算

- 补全菜单高度未计入动态行预算：流式输出期间输入 / 或 @ 可将内容推过终端边缘并使光标越顶。菜单高度现在经与编辑器增长相同的单向通道回报并精确扣除。
- 审批与问题面板可作为两个全高面板堆叠，超出终端。两者同时挂起时问题面板取得预算，审批条降级为单行摘要。
- 流式文本在极窄终端上强制十列最小宽度，将每行换行到第二个未预算行。宽度现在随物理终端收缩，行携带截断兜底。
- /theme 面板渲染固定七行而不考虑可用空间，在十四行终端上达到终端高度相等导致整屏每帧重写。主题行现在按可用空间切片并带光标跟随滚动。

### 输入与顺序正确性

- Backspace 与前向 Delete 共用同一按键标识；破坏性的队列取消操作此前在空 composer 上的习惯性 Backspace 即触发。取消现在要求前向删除键，与文档键位一致。
- 会话队列拼接保持上游原位顺序：插入 id 此前追加到队尾而非在给定位置拼接，后续定位事件可能删除错误的 pending 行。
- 提交投递按会话串行化：含会话 mention 的行此前经异步准备，而后续普通行同步投递越过它，模型以错误顺序看到用户消息。
- 会话创建后屏幕交接失败现在回滚已发布的会话，而非在报告失败的同时新会话实际存活。
- 切换 agent 后首次目录加载失败时保留上一个工作区的技能与命令行；目录现在在所属 agent 从未成功加载时清空。

## 改进

### 统一模型流程键位

- 供应商阶段从模型列表按 Tab 进入，与配置页既有的「往深一层即 Tab」约定一致；Ctrl+C 可从任意阶段退出整个 /model 流程——模型列表、供应商列表、配置页、发现页、选择页与档位选择页均消费该组合键并关闭浮层。
- 供应商列表将已配置条目稳定置顶，以一条灰色分隔线标注休眠区。已配置行以品牌强调色渲染，与灰色的未配置区一眼分层。

### 额外加固

- Windows deepseek update 命令经 shell 启动 npm.cmd，修复安装与版本检查两条路径。
- 发现在端点顺序上去重，防止可勾选列表出现重复行。
- 裸启动 @ 文件搜索按三十秒窗口刷新索引，首条会话前创建或删除的文件出现在（或离开）提及菜单。
