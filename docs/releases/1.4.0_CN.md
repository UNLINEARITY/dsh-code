# dsh-code 发行说明 - 1.4.0

## 概述

1.4.0 将供应商登录与子代理观察升级为一等的工作流。提供网页订阅的供应商现在直接在配置页上呈现「订阅或 Key」的通道选择，登录完成后路由自动切换到订阅通道。agents 面板可以把一个子代理会话附加为全屏实时视图，渲染与主对话完全一致，并实时流入 token 流。模型面板改为对齐的表格布局，runner 也会在与不兼容的 Harness 宿主组合时立即拒绝启动，而不是在会话中途失败。宿主线保持 `@deepseek-ai/dsh@0.1.5-rc.2`。

## 新工作流

### 供应商登录成为通道选择

- 供应商列表保持原有布局与回车行为；`l`/`o` 登录快捷键及其页脚提示移除。
- 提供网页订阅的供应商在配置页顶部增加通道层：订阅或 Key。选中订阅时，Tab 通过浏览器完成登录（仅有单一登录方式的供应商直接启动）；选中 Key 时，Tab 保持端点发现行为不变。
- 登录完成后，路由自动切换到订阅通道：剖面不再携带 Key 引用、端点与模型列表，由存储的登录凭据通过官方目录服务请求，并把目录的模型列表自动写入剖面。
- 两种通道同时配置时，配置页明确标出实际生效的通道，存储的 Key 不会再静默遮蔽套餐登录。

### 子代理实时观察

- 在 agents 面板中，回车仍先打开转录预览；再次回车即可把该子代理会话附加为整个视图。
- 附加视图使用与主对话相同的渲染管线：已落定的记录行进入同一份滚动缓冲，token 流与持久化事件从实时总线流入，底部为只读观察条和展示子代理信息的状态行。
- Esc 或 Ctrl+D 返回 agents 列表，Ctrl+C 与主会话一致退出应用，`r` 从持久化日志重新载入。重复事件按序号去重，流帧在历史载入完成前暂存，残留的流式内容不会重新出现。
- 转录预览本身增加带边框的近全屏展开（支持滚动与刷新），同样服务于 `/resume` 的转录查看。

## 界面改进

- 模型选择列表、供应商列表与配置页模型行改为对齐的表格布局：供应商名称、状态、密钥来源、登录状态、窗口容量与 image 标记跨行对齐，不再随字段宽度漂移。编辑括号恰好占用其替换的填充位，选中数值时列边界保持不动。
- 新增表面的中英文标签跟随所选界面语言，包括登录状态、观察条与展开文档的页脚。

## 可靠性

- runner 在挂载前识别已安装的 `dsh` 宿主，比对其版本与内置 `dsh-agent`/`dsh-session` 版本和声明的 Harness 快照。不匹配的宿主立即失败并列出实际版本与修复指引，而不是静默运行在未经校验的上游代码上。无法识别的宿主仍正常启动、不受干扰。
- 版本门禁声明的快照与 package manifest 通过契约测试绑定，后续 Harness 升级不会在两者之间漂移。

## 开发与架构

- 终端驱动重组为职责清晰的模块：`panels/` 承载独占键盘的模态面板，`ui/` 承载共享 Ink 原子与契约，`session/` 承载持久会话适配器，`runner/` 承载入口的决策与持久化 IO。每个目录绑定一条可机器校验的依赖规则，`src/index.ts` 的公开导出面保持不变。
- 会话目录 IO（选择器投影、带守卫的删除、导出渲染）通过窄接口注入，并由真实临时目录测试覆盖，包括租约顺序、跨进程占用与两类租约失败。
- 入口的启动收窄成为纯函数并由边界契约测试覆盖；4760 行的 App 测试拆分为七个按功能面划分的文件，共享一个 fixture 模块，无测试丢失。
- 测试套件增长到 81 个文件 / 1132 项测试，行覆盖率下限保持在 85%。

## 兼容性与升级说明

- Harness 依赖线未变；`@deepseek-ai/dsh@0.1.5-rc.2` 仍是受支持的宿主线。新增的版本门禁只在运行中宿主自身的版本与本构建声明的快照不一致时快速失败。
- 无配置迁移。
- 工作流变化：供应商登录与登出从列表的 `l`/`o` 快捷键移入供应商配置页。回车打开供应商，选中订阅通道后按 Tab 登录；已登录时在订阅行按回车即确认登出。
- `dsh-code/src/` 下移入子目录的深层导入路径在新路径解析；包的正式入口不变。
- npm 仍是主要渠道；GitHub Release 压缩包仍是受限网络的回退方式。推送 tag 会创建 GitHub Release 资产，但不会执行 `npm publish`。

从 1.3.0 升级：

```sh
npm install -g dsh-code@1.4.0
dsh plugin --profile cli add dsh-code@1.4.0
```

然后 `/quit` 并重新启动。npm 安装可以覆盖 GitHub 压缩包安装。在 npm 收录 1.4.0 之前，更新器会报告 1.4.0 压缩包安装更新并拒绝降级。
