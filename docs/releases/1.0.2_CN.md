# dsh-code 发布说明 - 1.0.2

## 概览

1.0.2 是一次终端交互与渲染改进版本。它让快速输入下的多行编辑更加可靠，将思考内容与工具输出统一到一套清晰的折叠状态中，并改善工作区引用的响应速度，同时不改变底层 Harness session 模型。

## 主要改进

### 输入框与编辑器行为

- 输入框在自动换行和多行草稿中保持唯一权威光标，避免移动、编辑、动画和窗口变化时出现重复或错位光标。
- 单词移动与删除遵循当前词片段和 Unicode 字素边界，包括中文文本；逻辑行 Home、End、kill 和 yank 操作使用同一套编辑模型。
- 批量到行首、到行尾、Delete 和 Backspace 按原顺序处理，Kitty CSI-u 按键序列会在交给 Ink 前完成规范化。
- 每次编辑或移动后恢复光标可见状态；异步图片检查与提交支持取消，同时保留草稿、附件和光标位置。

### 转录、思考与工具输出

- Ctrl+R 现在在实时输出和已结算转录中统一控制思考与工具详情的折叠状态。
- 工具卡片默认最多显示三行，超出内容以紧凑提示标记；Ctrl+O 继续提供选中条目的完整详情视图。
- 流式、已结算和重放的思考内容继续使用同一份源数据表示，同时将回合中的实时更新限制在有界区域内。
- `Deep diving...` 使用更缓慢的两秒蓝色 shimmer，并以前置 `✻` 持续呼吸；输入框忙碌提示保留原来的八帧 braille 点阵动画。

### 工作区引用

- `@src/` 等路径型查询在进入工作区目录时跳过无关的 session 搜索。
- mention 查询增加轻量防抖，在新查询完成前保留当前候选，并拒绝已被替代的响应。
- 裸 `@` 查询继续支持工作区文件和 session 引用，现有插入及目录导航行为保持不变。

## 问题修复

### 快速终端输入

- 补全接受后紧随的文本现在基于最新草稿和光标状态处理，避免字符丢失和旧菜单状态残留。
- bracketed paste 标记和仅供编辑器使用的控制序列不再在终端输入合并时泄漏到草稿。
- 终端协议的启停与 TUI 生命周期保持配对，回合中断或结束后不会遗留已启用的键盘模式。

## 兼容性与升级说明

- dsh-code 1.0.2 要求 `@deepseek-ai/dsh@0.1.1-rc.2`；Harness 依赖仍精确锁定在该版本线。
- 已有 session 无需迁移。
- 发布首日 pnpm 用户应安装精确版本 `dsh-code@1.0.2`；npm 安装不受 pnpm 发布后 24 小时延迟影响。
