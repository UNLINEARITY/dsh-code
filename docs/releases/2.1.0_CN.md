# dsh-code 更新说明 - 2.1.0

## 概览

2.1.0 对齐 DeepSeek Harness `0.2.1-rc.4`。模型面板可以发现已安装目录之外的订阅模型，并将选中的 Codex 候选模型导入 Harness。状态栏跟随工作目录变化；终端修复避免异步模型目录日志覆盖欢迎界面。

## 模型发现与选择

- `/model` 在已注册模型之外补充 DeepSeek Account 模型列表与 pi 的公开 Codex 目录。目录请求失败时仍保留已注册模型；Codex 发现也可读取 pi 的本地目录缓存。
- 远程目录中尚未注册的 Codex 模型显示为候选项。按 Enter 后先通过 Harness 设置导入，再应用选择，同时保留已有模型和自定义配置。提供方设置存在冲突或只读时会显示错误，不覆盖原配置。
- Codex 目录条目携带经过校验的上下文限制、输入类型与推理等级。已注册模型继续使用适配器提供的能力；导入后不提供不受支持的推理等级。
- 目录结果缓存四小时。在 `/model` 中刷新会绕过 Codex 目录缓存。Codex 发现使用公开目录数据，不读取 pi 的 OAuth 凭据；模型请求继续使用 Harness 中已配置的提供方。

## 工作目录、预设与语言

- 状态栏中的目录与 Git 分支跟随已提交的工作目录变化，恢复会话时也会应用这些变化。
- `standard`、`ptc`、`cordis` 预设跟随上游声明时钟上下文。`minimal` 预设增加图片读取及独立的上下文压缩组。提醒工具仍依赖 Web 投递服务，在当前终端组合中不可用。
- 中文面板标签与权限预设名称对齐上游术语。主 README 改为英文，中文说明位于 `README_CN.md`。

## 终端修复

- 异步 console 日志与 Ink 输出共用光标恢复路径；IME 光标位于输入框时，account 模型列表日志不再覆盖欢迎界面的 header。
- Ink 在超高帧恢复后同步行数记录，并在历史 remount 时重置累积的 Static 输出，避免这些恢复路径中的旧行残余和历史重复。转录预算计入状态栏的实际高度。
- 在 macOS Terminal.app 中，鲸鱼 header 的整块使用背景色单元格绘制，避免行距造成条纹；半块轮廓在该终端中仍有轻微对齐问题。

## 兼容性与升级

发行 tarball 携带已审计的生产依赖，使安装后保留修复版本，安装包体积也相应增大；宿主依赖另由下方安装步骤中的修复命令处理。

- 要求 Node `^22.19 || >=24`，宿主精确为 `@deepseek-ai/dsh@0.2.1-rc.4`。宿主、DSH-Code 和单独安装的 Harness profile 插件需要一起升级；rc.2、rc.3 宿主无法加载此 bundle。
- `deepseek repair-deps` 在现有宿主安装位置，通过限定版本的 overrides 使用 Zod `4.6.6`、Undici `8.12.2`、MCP client `2.3.0`、fflate `0.8.3`。该命令备份清单与锁文件，保留 Harness 版本，核对实际解析路径，并执行生产依赖审计。setup 与更新流程已包含此步骤；手动重装宿主后需要重新执行。`deepseek repair-deps --check` 与 `deepseek doctor` 只检查实际版本，不修改文件。
- Harness 0.2.1 删除了 `{{cwd}}` 提示变量以及已停用的 invariant、Ralph 行。内置预设已更新；自定义 profile patch 中的旧条目需要移除。工作目录通过运行时上下文提供。
- 宿主不再捆绑 Claude Code、Codex 钩子桥。使用时需将钩子桥与 `@deepseek-ai/dsh-hook-protocol` 一起装入 profile，均使用 `0.2.1-rc.4`。详见[升级排障表](../installation_CN.md#升级与安装排障)。

升级前先关闭所有正在运行的 `dsh`、`deepseek` 会话。npm 安装执行：

```sh
npm install -g --allow-scripts=@deepseek-ai/dsh-subprocess-local,koffi,node-pty,@google/genai,protobufjs @deepseek-ai/dsh@0.2.1-rc.4
npm install -g dsh-code@2.1.0
deepseek repair-deps
dsh plugin --profile cli add dsh-code@2.1.0
```

如果 profile 中单独声明了 `@deepseek-ai/dsh-tool-session-query`，也要同步升级：

```sh
dsh plugin --profile cli add @deepseek-ai/dsh-tool-session-query@0.2.1-rc.4
dsh --profile cli --dump-config
deepseek doctor
```

确认组合输出中没有版本不匹配、`skipping` 或 `disabling` 提示。使用本地 `link:` checkout 时，执行 `pnpm install && pnpm build` 并保留本地挂载，不要替换为 npm bundle。profile 迁移错误的处理方法详见[安装、升级与排障](../installation_CN.md)。
