# DSH-Code 2.2.0

[English](https://github.com/UNLINEARITY/dsh-code/blob/2.2.0/docs/releases/2.2.0.md) | 中文

DSH-Code 2.2.0 支持 DeepSeek Harness `0.2.2-rc.5`。安装终端组件时会复用 dsh 已安装的运行时依赖，减少重复下载。

## 模型与子代理

- 每个会话都会保存模型和推理档位。即使在发送第一条提示词前选择模型，恢复会话时也能沿用该设置。
- 子代理从第一次请求起就使用为它指定的模型。未单独指定时，子代理使用父会话的模型。
- `standard`、`cordis` 和 `ptc` 预设从模型的默认工具列表中移除了 `interrupt_agent`。你可以在 `/agents` 中中断子代理。

## 安装或升级

请使用 Node.js 24.9.0 或更高版本。安装或升级前，先退出所有正在运行的 `dsh` 和 `deepseek` 会话，再执行以下命令。

```sh
npm install -g --allow-scripts=@deepseek-ai/dsh-subprocess-local,koffi,node-pty,@google/genai,protobufjs @deepseek-ai/dsh@0.2.2-rc.5 pnpm
npm install -g dsh-code@2.2.0
deepseek setup
```

运行 `deepseek` 打开终端界面。如果 profile 中有单独安装的 Harness 插件，请同步升级到 `0.2.2-rc.5`。dsh 已提供会话查询工具，可以移除单独安装的 `@deepseek-ai/dsh-tool-session-query`。

源码挂载的升级方式和常见安装错误的处理方法，请参阅[安装、升级与排障](https://github.com/UNLINEARITY/dsh-code/blob/2.2.0/docs/installation_CN.md)。
