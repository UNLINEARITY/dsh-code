# dsh-code 发布说明 - 1.1.0

## 概览

1.1.0 是 1.0.8 打包修复之后的第一个功能版本。终端支持中英文界面，新增 prismatic、rainbow 两套配色；npm 仍暂停，安装走 GitHub Release tarball。审查、diff、搜索、嵌套工具轨迹和欢迎页头部也一并跟上 1.0.8 以来的改动。宿主版本线仍是 `@deepseek-ai/dsh@0.1.5-rc.2`。

## 新功能

### 语言

- `/language` 与 `/language en|zh` 切换界面，默认英文。面板框架、帮助、命令说明、通知、相对时间和审查汇总随语言变化。模型提示词和状态栏里的事实数据仍为英文。切换语言会整屏重绘。

### 主题

- **prismatic** — 电紫、品红、青色铺在现有色位上。面板边框轮换四色。微光、忙碌标记、状态栏圆点和模型切换动画沿 2.4 秒紫到青的流光，关闭动画即静止。diff 和语义绿红与 dark 相同。
- **rainbow** — 每次启动把十二色亮色谱打乱，铺到品牌色、强调色、状态栏和 diff 行，黑底上仍然清晰可读。`/rainbow` 换一颗种子（若当前不是彩虹会先切过去）；`/rainbow <seed>` 指定这次配色。`RAINBOW_SEED=<seed>` 可复现某次启动。切到 rainbow 或重掷种子时，输入框会扫过 1.8 秒红到紫。欢迎页鲸鱼使用同一套固定色谱，不跟打乱后的种子走。
- `/theme` 和 `--theme` 可选 `dark`、`light`、`prismatic`、`rainbow`、`auto`。

### 审查、diff 与搜索

- `/review` 弹出选择器：未提交改动、基线分支、某次提交或自定义范围。后面的文字作为对未提交 diff 的说明（例如 `/review 使用中文`）。审查仍在当前会话里以普通回复给出。粘贴的 ` ```diff ` 使用与 `/diff` 相同的红绿整行着色。
- diff 新增/删除行使用整行底色，并有单独的前景色，在行底色和纯背景上都清晰可读，包括 16 色终端。
- `/search` 按内容查找历史会话并恢复选中项。

### 输入框与工具

- `Ctrl+J` 和 `Alt+Enter` 插入换行（支持的终端还有 `Shift+Enter` / `Ctrl+Enter`）。回车仍发送。
- `run_code` 会列出正在执行的子工具调用（状态、耗时、错误）。workflow 会列出各成员直到结束。
- 恢复会话会带上子代理列表和网页端选过的模型。

## 改进

- 在 `/theme` 中换主题时，欢迎页头部和历史记录会与输入框、面板一起换色。
- 欢迎页同时显示正在运行的 dsh 版本（`dsh-v…`）和 dsh-code 版本；用 `deepseek` 经全局 `dsh` 软链启动也能读到。
- Ctrl+O 标题会标明条目种类（user prompt、reply、tool call 等）。只调用了工具、没有正文的步骤不再留下空白卡片。
- 回合进行中连按 Shift+Tab 时，plan 档会继续往前走。
- macOS 上 VS Code 集成终端标签会显示 deepseek 和会话名，而不再显示 node。
- 中文文档把直译换成自然说法（限高限宽、回放、派生视图缓存）。

## 更新与打包

- npm 暂停期间，安装和升级用 GitHub Release tarball。`/update` 仍只查 npm，恢复前不要用它升级。
- npm 恢复后，在 `/update` 里确认会安装刚才看到的版本，不会再查一次 `latest`。
- 通过 GitHub 安装会领先 npm，面板会写明不降级，而不再说已是最新。
- 本地 `link:` / `file:` 挂载会拒绝升级（读不到 checkout 版本时也拒绝）。请先构建工作区，或改挂 tarball。
- 推送 tag 会把打包产物挂到 GitHub Release。推 `main` 不会发 Release，也不会 `npm publish`。
- 启动器在 git 里保留可执行位，link 挂载的 profile 可以直接运行 `deepseek`。

## 升级须知

- 本版本不要用 `/update`。按 GitHub tarball 重装，然后 `/quit` 再启动：

  ```sh
  npm install -g @deepseek-ai/dsh@0.1.5-rc.2 pnpm
  npm install -g https://github.com/unlinearity/dsh-code/releases/download/1.1.0/dsh-code-1.1.0.tgz
  dsh plugin --profile cli add https://github.com/unlinearity/dsh-code/releases/download/1.1.0/dsh-code-1.1.0.tgz
  ```

- 界面默认英文。中文界面请执行 `/language zh`。
