# dsh-code 发布说明 - 0.5.0

## 概览

0.5.0 将 DSH-Code 完善为更完整的 DeepSeek Harness 终端工作流。会话现在可选择并持久化 Agent Preset、无需重启 TUI 即可创建或恢复，并可检查当前插件组合。本次发布还强化了长时间运行的终端交互，加入直接全局启动命令，并补齐安装排障路径。

## 新功能

### 会话工作流与 Agent Preset

- `/mode` 与 `--mode <preset>` 可在首个 turn 前选择会话级 Agent Preset。`standard`、`code`、`minimal`、`cordis` 与用户预设决定该会话的 Agent 能力，并会在恢复时还原。
- `/new` 无需重新挂载终端即可创建并进入另一会话。`/resume` 提供可搜索的会话目录，支持 cwd、排序、密度、根/全部对话筛选、只读 subagent 检查和按需查看完整转录。
- `/plugin` 显示组合后的 Cordis loader 清单，包括条目身份、启用状态与生命周期阶段。

### 直接启动终端

- `deepseek`、`dsh-code` 与 `dsh --profile cli` 是并列的启动命令。前两者会将 `--resume`、`--continue` 等后续参数转发到 `cli` profile。
- npm 启动器支持 Linux、macOS 与 Windows。Windows 直接调用 DSH JavaScript 入口而非命令 shell，并支持 `npm install -g .` 链接到本地 checkout 的开发方式。

## 终端可靠性与交互

- 命令、技能、模型目录和 runner 边界的失败会显示为有界 notice 或可恢复面板状态，不再终止 Ink 界面。`/model` 可原位重试，`/help` 会保留目录加载错误。
- Ctrl+O、帮助、模型选择、审批、问题、mode 选择、会话恢复和插件检查共享有界可滚动面板。长内容不会再触发整屏重写，并会保留输入框和状态栏。
- 连续缩放会在最终宽度根据持久转录只重排一次。输入草稿、面板状态和底部顺序——内容或面板、notice、输入框、状态栏——保持稳定。
- Markdown、CJK 截断、紧凑终端、思考折叠、补全与 Esc 输入所有权均采用明确的行列预算。

## 安装与排障

- GitHub 源码安装通过 `prepare` 构建所需的 `lib/` 输出。若 pnpm 请求许可，请将其输出的完整 Git URL 与 commit `allowBuilds` 键复制到 profile workspace 配置中。
- 新增排障指南，覆盖 Git 准备阶段失败、pnpm PATH 设置和 Linux `node-pty` 恢复。若缺少 `pty.node`，请安装原生构建工具链，并使用 `node-gyp` 重建已安装的 `node-pty` 包。

## 重要说明

- 从 0.4.0 升级无需迁移配置或持久会话。已有会话在记录新的选择前默认使用 `standard` preset。
- 使用全局别名时，请全局安装两个包，将 DSH-Code 添加到 `cli` profile，再使用任一并列启动命令：

  ```sh
  npm install -g @deepseek-ai/dsh@next dsh-code
  npm install -g pnpm
  dsh plugin --profile cli add dsh-code
  deepseek
  ```

- 运行要求保持为 Node `^22.19 || >=24`，并需要兼容的 `@deepseek-ai/dsh@next` 安装。
