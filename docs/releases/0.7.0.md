# dsh-code Release Notes - 0.7.0

## Overview

Version 0.7.0 turns model switching into a moment: switching to an official DeepSeek model (or changing its reasoning effort) plays a Codex-style ignition celebration inside the composer, and the reasoning effort itself is now selectable and shown in the status bar. A light color theme joins the default dark one, the context meter becomes a segmented per-type bar, and the completion index — which never actually loaded for `@` — is repaired and fully live. This release covers everything since 0.6.0, including the 0.6.1 stability fixes.

## New features

### Model switching and reasoning effort

- Switching to an official DeepSeek route plays a one-shot ignition animation in the composer, ported from Codex: three styles — a **Wave** crest sweeping the input row, an **Aurora** drifting multi-hue band, and a **Pulse** expanding ring — chosen at random without repeating, at a smooth 33 ms cadence. The border glows with the tier accent, the `deepseek` wordmark surfaces mid-wave, pro models end with a trail of sparkles, and the prompt marker switches to the tier glyph (`›` for flash, `»` for pro) and stays colored until you switch away. Changing the reasoning effort on the same model replays the animation.
- Reasoning effort is now a first-class setting: `/model` opens an effort stage for models that advertise multiple levels, and a new `/effort` command resolves the current model and opens the same stage. The status bar shows the effective level as `provider/model@effort`.
- You can pick a model before the first message: on a bare launch the choice is kept and applied to the first composed session (previously `/model` failed with "no session yet").

### Theme

- A **light theme** joins the default dark one, tuned for white terminal backgrounds with contrast-driven values. `/theme` switches dark/light/auto, the choice persists to `~/.dsh/dsh-code/theme.json`, and `--theme <dark|light|auto>` overrides it at launch. Every color in the UI derives from the active palette.

### Terminal feel

- The context-occupancy meter is now a segmented bar: five DeepSeek-blue segments by content type (system / prompt / assistant / thinking / tools) with adaptive labels and a right-aligned usage readout such as `32K/128K 25%`.
- The status-bar model name matches the working-directory tone — the long-standing gray look is gone (see Fixes), and the effective reasoning effort is displayed alongside.

### Completion

- The `@` mention index is live: file and directory candidates come from a bounded workspace scan, appear even before the first message, and files are always ranked before session references. Previously the menu never loaded at all (see Fixes).
- The `/` menu now lists the full command catalog — local commands, registry commands, and skills — with an item count and a "+N more" scroll hint, so skills are discoverable by default instead of appearing only after typing.

## Bug fixes

- **`@` completion never loaded**: the runner passed the mention API as a detached function and every keystroke threw on an unbound `this`, leaving the menu stuck on "searching…". The API no longer depends on method binding.
- **`/effort` reported "capability lookup failed" for every model**: the model directory called `resolveModelInfo` with a detached `this`, so every lookup threw into a swallowed catch. Capability lookups now run on the service, the adapter's off/high/max levels load, and a failed lookup is reported separately from a model that genuinely has no levels.
- **The model name looked gray/dim**: an unclosed SGR `dim` from the busy dot leaked into the following span through Ink's token stream. Status labels, meta, and separators now use an explicit palette gray, and the model name renders in the same tone as the working directory.
- **First-input ghosting (from 0.6.1)**: the deferred-session remount and the queued-prompt row no longer paint duplicate headers or duplicate first messages on screen.
- **Launcher hang (from 0.6.1)**: `deepseek` / `dsh-code` now check that the cli profile mounts dsh-code before starting and print the missing install step instead of hanging on a bare profile.

## Important notes

- Upgrade from 0.6.0 or 0.6.1 requires no configuration or persisted-session migration.
- Runtime requirements remain Node `^22.19 || >=24` and a compatible `@deepseek-ai/dsh` installation.
- The light theme assumes a light terminal background (it deepens the foreground colors); on dark terminals keep the dark theme.
- On the release day, pnpm users should pin the exact version `dsh-code@0.7.0` because pnpm ignores packages published less than 24 hours ago.
