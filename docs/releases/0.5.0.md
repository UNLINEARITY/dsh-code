# dsh-code Release Notes - 0.5.0

## Overview

Version 0.5.0 makes DSH-Code a more complete terminal workflow for DeepSeek Harness. Sessions can now select and preserve Agent Presets, be created or resumed without restarting the TUI, and expose their active plugin composition. The release also hardens long-lived terminal interaction, adds direct global launch commands, and documents installation recovery paths.

## New features

### Session workflows and Agent Presets

- `/mode` and `--mode <preset>` select a session-scoped Agent Preset before the first turn. `standard`, `code`, `minimal`, `cordis`, and user presets determine the Agent capabilities for that session and are restored on resume.
- `/new` creates and enters another session without remounting the terminal. `/resume` provides a searchable session directory with cwd, ordering, density, root/all-conversation filters, read-only subagent inspection, and opt-in full transcript viewing.
- `/plugin` shows the composed Cordis loader inventory, including entry identity, enabled state, and lifecycle phase.

### Direct terminal launch

- `deepseek`, `dsh-code`, and `dsh --profile cli` are parallel launch commands. The first two forward all following arguments to the `cli` profile, including `--resume` and `--continue`.
- The npm launcher works on Linux, macOS, and Windows. Windows launches DSH through its JavaScript entrypoint rather than a command shell, and also supports `npm install -g .` links to a local checkout.

## Terminal reliability and interaction

- Commands, skills, model discovery, and runner-boundary failures remain as bounded notices or recoverable panel states instead of terminating the Ink surface. `/model` can retry in place, and `/help` keeps catalog failures visible.
- Ctrl+O, help, model selection, approvals, questions, mode selection, resume, and plugin inspection use bounded scrollable panels. Long content preserves the composer and status line rather than triggering a full-screen rewrite.
- Resize bursts reflow once from the durable transcript at the settled width. The draft, panel state, and bottom order—content or panel, notice, composer, status—remain stable.
- Markdown, CJK truncation, compact terminals, thinking folds, completion, and Esc input ownership now share explicit row and column budgets.

## Installation and troubleshooting

- GitHub source installations build their required `lib/` output through `prepare`. When pnpm requests approval, copy its complete Git URL-and-commit `allowBuilds` key into the profile workspace configuration.
- The new troubleshooting guide covers Git preparation failures, pnpm PATH setup, and Linux `node-pty` recovery. For a missing `pty.node`, install the native build toolchain and rebuild the installed `node-pty` package with `node-gyp`.

## Important notes

- No configuration or persisted-session migration is required from 0.4.0. Existing sessions default to the `standard` preset until a new selection is recorded.
- To use the global aliases, install both packages globally, add DSH-Code to the `cli` profile, then run one of the parallel launch commands:

  ```sh
  npm install -g @deepseek-ai/dsh@next dsh-code
  npm install -g pnpm
  dsh plugin --profile cli add dsh-code
  deepseek
  ```

- Runtime requirements remain Node `^22.19 || >=24` and a compatible `@deepseek-ai/dsh@next` installation.
