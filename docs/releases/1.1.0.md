# dsh-code Release Notes - 1.1.0

## Overview

1.1.0 is the first feature release after the 1.0.8 packaging hotfix. The terminal now speaks English or Chinese, ships two extra color themes (prismatic and rainbow), and treats npm as the real install and `/update` channel. Review, diffs, search, nested tool traces, and the welcome header all pick up the rest of the work that landed since 1.0.8. The harness line stays `@deepseek-ai/dsh@0.1.5-rc.2`.

## New features

### Language

- `/language` and `/language en|zh` switch the interface. English is the default. Panel chrome, help, command descriptions, notices, relative times, and review summaries follow the selected language. Model prompts and factual status values stay in English. Switching language repaints the whole screen.

### Themes

- **prismatic** — neon violet, fuchsia, and cyan over the existing tokens. Panel borders cycle a four-color ring. Shimmer, the busy marker, the status live dot, and the model-switch wave follow a 2.4-second violet-to-cyan flow that stops when animations are off. Diff and semantic green/red stay the same as dark.
- **rainbow** — each launch shuffles a twelve-color bright spectrum across brand, accents, status, and diff rows, kept readable on black. `/rainbow` rolls a new seed (and switches to rainbow if needed); `/rainbow <seed>` pins that look. `RAINBOW_SEED=<seed>` reproduces a launch. Switching to rainbow or rerolling plays a 1.8-second red-to-violet sweep on the input box. The welcome whale uses the same fixed spectrum, independent of the shuffled seed.
- `/theme` and `--theme` accept `dark`, `light`, `prismatic`, `rainbow`, and `auto`.

### Review, diffs, and search

- `/review` opens a picker for uncommitted changes, a base branch, a commit, or a custom focus. Extra arguments become a note on the uncommitted diff (`/review 使用中文`). The review stays in the current session as a normal reply. Pasted ` ```diff ` fences use the same full-row green/red as `/diff`.
- Added and removed diff lines use full-row backgrounds, with dedicated foreground colors that stay readable on tinted and plain backgrounds, including 16-color terminals.
- `/search` finds persisted sessions by content and resumes the pick.

### Composer and tools

- `Ctrl+J` and `Alt+Enter` insert a newline (`Shift+Enter` / `Ctrl+Enter` where the keyboard protocol allows). Enter still sends.
- `run_code` lists nested tool calls as they run (state, duration, errors). Workflow runs list their member agents until they finish.
- Resume keeps the subagent list and the model chosen in the web UI.

## Improvements

- Changing theme in `/theme` recolors the welcome header and history together with the composer and panels.
- The welcome header shows the running dsh version (`dsh-v…`) next to the dsh-code version, including when launched with `deepseek` through a global `dsh` symlink.
- Ctrl+O titles name the kind of each entry (user prompt, reply, tool call, and so on). Steps that only called tools no longer leave blank transcript cards.
- Shift+Tab keeps moving through the plan station while a turn is running.
- On macOS, the VS Code tab title is written where VS Code actually reads it, so integrated-terminal tabs show `deepseek` and the session name instead of `node`.
- Chinese docs use everyday wording (限高限宽, 回放, 派生视图缓存) in place of literal calques.

## Updates and packaging

- Install and `/update` use npm. GitHub Release tarballs remain for development and emergencies.
- Confirming in `/update` installs the versions that were shown, not a later `latest`. A CLI `deepseek update --apply` with no pins still probes then applies.
- When this install is newer than npm, the panel says so and refuses to downgrade instead of claiming everything is up to date.
- A local `link:` / `file:` mount is refused (including when the checkout version cannot be read) so a new host is not paired with old local code. Rebuild the checkout, or switch the profile to the published package.
- The launcher keeps the executable bit in git so a link-mounted profile can run `deepseek` without an extra `chmod`.

## Upgrade notes

- From 1.0.8: `deepseek update --apply`, or in a running terminal `/update`, then `/quit` and relaunch.
- Fresh install:

  ```sh
  npm install -g @deepseek-ai/dsh@0.1.5-rc.2 pnpm
  npm install -g dsh-code@1.1.0
  dsh plugin --profile cli add dsh-code@1.1.0
  ```

- pnpm ignores packages published less than 24 hours ago. Use the exact version on release day.
- Interface language defaults to English. Run `/language zh` for Chinese chrome.
