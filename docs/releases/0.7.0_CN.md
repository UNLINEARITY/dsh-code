# dsh-code 发布说明 - 0.7.0

## 概览

0.7.0 让模型切换成为值得一看的时刻：切换到官方 DeepSeek 模型（或调整其推理档位）时，输入框内播放移植自 Codex 的点火庆祝动画；推理档位本身也可选择并在状态栏显示。浅色主题加入默认深色，context 仪表改为按内容类型分段，`@` 自动补全——此前从未真正加载——修复后完全可用。本版本覆盖 0.6.0 以来的全部变化，含 0.6.1 的稳定性修复。

## 新功能

### 模型切换与推理档位

- 切换到官方 DeepSeek 路由时播放一次性点火动画（移植自 Codex）：三种风格——**Wave**（余弦波扫过输入行）、**Aurora**（多色光带正弦漂移）、**Pulse**（中心扩散环）——随机选择且不重复，33ms 平滑帧率。边框随档位 accent 呼吸，`deepseek` 字样在波中段浮现，pro 模型以星光收尾，提示符切换为档位字形（flash `›` / pro `»`）并保持彩色直到切换离开。同一模型调整推理档位时重放动画。
- 推理档位成为一等设置：`/model` 对公告多档位的模型打开档位面板，新增 `/effort` 命令解析当前模型并打开同一面板。状态栏以 `provider/model@effort` 显示当前有效档位。
- 首条消息前即可预选模型：裸启动时选择会保留并应用于首个组合的会话（此前 `/model` 会报 "no session yet"）。

### 主题

- 新增面向白色终端背景的**浅色主题**（对比度驱动取值）。`/theme` 在 dark/light/auto 间切换，选择持久化到 `~/.dsh/dsh-code/theme.json`，`--theme <dark|light|auto>` 启动参数优先级最高。界面全部颜色取自当前主题调色板。

### 终端质感

- context 占用仪表改为分段条：按内容类型（system / prompt / assistant / thinking / tools）五段 DeepSeek 蓝渐变、自适应标签、右侧右对齐 usage 读数（如 `32K/128K 25%`）。
- 状态栏模型名与工作目录同色——长期存在的灰色观感消失（见修复），并同步显示当前有效推理档位。

### 自动补全

- `@` mention 索引已修复并实时可用：文件与目录候选来自有界工作区扫描，首条消息前即可使用，文件恒排在会话引用之前。此前菜单完全不加载（见修复）。
- `/` 菜单现在列出完整命令目录——本地命令、registry 命令与 skills——并显示条目计数与 "+N more" 滚动提示，skills 默认可见，不再需要输入关键字才出现。

## 修复

- **`@` 补全从不加载**：runner 以裸函数传递 mention API，每次按键都在未绑定的 `this` 上抛错，菜单卡在 "searching…"。API 不再依赖方法绑定。
- **`/effort` 对所有模型报 "capability lookup failed"**：模型目录以解绑的 `this` 调用 `resolveModelInfo`，每次查询都抛错并被静默吞掉。能力查询现在在服务上调用，适配器的 off/high/max 档位可正常加载；查询失败与真正无档位的模型分开上报。
- **模型名显灰/变暗**：忙碌圆点的未闭合 SGR `dim` 经 Ink 的 token 流泄漏进相邻 span。状态 label/meta 与分隔符改用显式调色板灰色，模型名与工作目录同色渲染。
- **首次输入鬼影（0.6.1 起）**：延迟会话重挂载与排队提示行不再在屏幕上重复渲染头部或首条消息。
- **launcher 挂起（0.6.1 起）**：`deepseek` / `dsh-code` 启动前检查 cli profile 是否挂载 dsh-code，未挂载时打印安装步骤并退出，不再在空 profile 上挂起。

## 重要说明

- 从 0.6.0 或 0.6.1 升级无需迁移配置或持久会话。
- 运行时要求保持 Node `^22.19 || >=24` 与兼容的 `@deepseek-ai/dsh` 安装。
- 浅色主题假设终端背景为浅色（它会加深前景色）；深色终端请保持 dark 主题。
- 发布首日 pnpm 用户请使用精确版本 `dsh-code@0.7.0`（pnpm 会忽略发布不足 24 小时的包）。
