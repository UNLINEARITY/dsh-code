# dsh-code Release Notes - 1.5.0

## Overview

1.5.0 focuses on terminal continuity: long conversations now settle into native scrollback through a physical-row viewport, while the composer and status footer remain stable once real content reaches the bottom of the terminal. Tool cards and Ctrl+O show less duplicate or low-value detail, and turning decorative animations off no longer makes active work appear frozen. The release also adds explicit compatibility, architecture, and performance guards around the pinned Harness line, which remains `@deepseek-ai/dsh@0.1.5-rc.2`.

## Terminal and transcript improvements

### Stable physical-row viewport

- Sparse conversations continue to use natural terminal flow. Once real transcript content fills the viewport, settled physical rows move monotonically into native scrollback while a bounded live tail keeps the composer and status footer stable.
- Streaming contraction, tool settlement, and oversized entries refill the viewport with real history instead of synthetic blank padding. Long entries can split precisely between native scrollback and the live viewport.
- The main conversation and attached subagent view use the same row accounting. Resize and Ctrl+L rebuild from source-backed history, preserving full replay without an alternate screen.
- Exclusive panels such as `/help` retain frozen real transcript history above them rather than clearing the conversation or padding the screen.
- The status line reserves the terminal's final column, preventing VS Code's exact-width autowrap from creating an untracked row and pushing the footer upward on the first token.

### Clearer tools and history inspection

- Tool previews recognize `file_path` and named targets, including bounded extraction from oversized write/edit arguments, so cards show concise paths instead of large JSON payloads.
- Expanded raw, read, and structured-diff details replace equivalent summaries. Single-line command output is no longer repeated or followed by a false hidden-output hint, while supplemental web metadata and errors remain visible.
- Tool names use theme accents and status markers keep semantic colors; ordinary reasoning, parameters, summaries, and raw output stay muted. Only structured diff details receive themed add/delete styling—raw Bash output is never guessed to be a patch.
- Ctrl+O excludes assistant settlements that contain reasoning but no final response text from navigation and entry counts. The durable events remain available to the normal transcript, reasoning toggle, export, and resume paths.

### Necessary activity remains visible

- `/animation off` now disables only decorative model-switch waves/pulses, animated theme flow, and rainbow bursts.
- Input and streaming carets, the busy chase, Thinking/Deep Diving shimmer, and the `Deep diving...` elapsed clock remain live so active work does not look frozen.
- The elapsed clock owns a low-rate timer and continues advancing even when no transcript or store event arrives.

## Reliability and performance

- Every session event known by the pinned Harness snapshot is explicitly classified as transcript-visible, handled by another terminal surface, or deliberately ignored. Unknown third-party plugin events remain compatible no-ops, while a missing first-party transcript reducer now fails visibly instead of drifting silently.
- The private session-query override validates the upstream `_observeStable` contract before mounting, preventing an upstream signature change from silently removing corrupt-session isolation.
- `/resume` artifact inspection uses a fixed 16-worker pool instead of opening every persisted session directory at once. Ordering, missing-artifact fallback, and cancellation behavior are unchanged.
- Runtime import-cycle checks cover the full source graph and enforce the documented runner, panel, UI, and session dependency boundaries without treating type-only imports as runtime coupling.
- Cross-platform performance budgets now guard 100,000-event replay, 3,000-entry settled-history reflow, and live snapshots over 100,000 entries. The limits are deliberately broad enough to detect algorithmic regressions without reacting to ordinary scheduler noise.

## Development and release safeguards

- Focused regression coverage was expanded across terminal layout, tools, adapters, questions, permissions, model effort, provider setup, projection compatibility, architecture, and long-session performance.
- CI continues to publish V8 coverage totals for trend visibility, but behavioral regressions, typechecks, builds, and performance budgets—not a global percentage threshold—are the quality gates.
- The standard verification and `prepublishOnly` paths now include the long-session performance check.

## Compatibility and upgrade notes

- No Harness peer line changed; `@deepseek-ai/dsh@0.1.5-rc.2` remains the supported host line.
- There are no configuration migrations and no documented package entry-point changes.
- Behavior change: `/animation off` is now a decorative-motion preference rather than a global timer freeze. Necessary activity indicators and shimmer continue to run.
- Behavior change: Ctrl+O no longer counts reasoning-only assistant settlements as separate inspectable replies; no durable session data is removed.
- npm remains the primary channel; the GitHub Release tarball remains the fallback for restricted networks. A tag push creates the GitHub Release asset but does not run `npm publish`.

Upgrading from 1.4.0:

```sh
npm install -g dsh-code@1.5.0
dsh plugin --profile cli add dsh-code@1.5.0
```

Then `/quit` and start again. A GitHub-tarball installation can be overwritten by the npm command. Until npm carries 1.5.0, the updater reports that a 1.5.0 tarball install is newer and refuses to downgrade.
