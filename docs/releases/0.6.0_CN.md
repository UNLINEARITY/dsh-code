# dsh-code 发布说明 - 0.6.0

## 概览

0.6.0 聚焦终端体验与生命周期：更快的冷启动、重新设计的双行状态栏（蓝色 context 占用仪表）、无缝的排队消息处理、跨会话输入召回，以及更生动的忙碌状态。会话现在只在真正输入内容时才创建。

## 新功能

### 启动与会话生命周期

- 启动显著提速：Ink 运行时（ink、react、chalk 及其传递依赖）已内联进包产物，bundle 加载从约 1 秒降到约 130ms，交互启动节省约一秒。
- 裸启动不再创建或持久化会话：终端以空转录打开，会话在首次真实输入时创建。未输入即退出零残留。`--resume`、`--continue`、`--session` 与 `--mode` 保持原有急切行为。

### 状态栏

- 状态栏改为两行：第一行身份事实与状态徽章，第二行 agent preset、context 占用、缓存与时长指标。
- context 占用渲染为括号包围的蓝色进度条（`context [▰▰▰▱▱▱▱▱▱▱] 25%`），仅超过 90% 转为单一琥珀警告。
- 整条状态栏只使用不同程度蓝色强调；参数改用完整单词标签（turns/steps、in/out、model/latency/tokens per second），取代单字母缩写。

### 排队消息与输入召回

- 运行中提交会立即以普通提示词行显示，agent 消费时无缝退役；空输入框按 Delete 取消最新排队消息。
- 输入历史全局持久化：Up/Down 跨会话召回之前的 prompt，`/history` 提供可搜索面板并从匹配项回填输入框。

### 终端质感

- 忙碌时输入框标记与 Deep-diving 行使用 web StateDot 追逐动画（八帧 braille 顺时针旋转，125ms/帧）。
- 助手回复缩进与输入框光标对齐，欢迎头字标提亮。

## 重要说明

- 从 0.5.0 升级无需迁移配置或持久会话。输入历史文件位于 `~/.dsh/dsh-code/history.jsonl`，首次提交时创建。
- 运行时要求保持 Node `^22.19 || >=24` 与兼容的 `@deepseek-ai/dsh@next` 安装。
