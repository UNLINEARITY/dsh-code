# dsh-code Release Notes - 0.6.0

## Overview

Version 0.6.0 focuses on terminal feel and lifecycle: a faster cold start, a redesigned two-row status bar with a blue context-occupancy meter, seamless queued-message handling, cross-session input recall, and livelier busy states. Sessions are now created only when you actually type something.

## New features

### Startup and session lifecycle

- Startup is significantly faster: the Ink runtime (ink, react, chalk and their transitive graph) is now bundled into the package, cutting the bundle load from about one second to roughly 130 ms and shaving about a second off interactive startup.
- A bare launch no longer creates or persists a session: the terminal opens with an empty transcript, and the session is created on your first real input. Quitting before any input leaves nothing behind. `--resume`, `--continue`, `--session`, and `--mode` keep their eager behavior.

### Status bar

- The status line is now two rows: identity facts and state badges on the first; agent preset, context occupancy, cache, and duration figures on the second.
- Context occupancy renders as a bracketed blue progress bar (`context [▰▰▰▱▱▱▱▱▱▱] 25%`) that flips to a single amber warning only above 90%.
- The whole bar speaks in degrees of blue, and figures use full-word labels (turns/steps, in/out, model/latency/tokens per second) instead of single-letter codes.

### Queued messages and input recall

- Submitting while a turn runs shows your message immediately as an ordinary prompt row, retired seamlessly when the agent consumes it. Delete on the empty composer cancels the newest queued message.
- Input history is now global and persistent: Up/Down recall previous prompts across sessions, and `/history` opens a searchable panel that fills the composer from a match.

### Terminal feel

- The busy composer marker and the Deep-diving line use the web StateDot chase animation (eight braille frames rotating clockwise, 125 ms per frame).
- Assistant replies are indented to align with the input cursor, and the welcome header wordmark is brighter.

## Important notes

- No configuration or persisted-session migration is required from 0.5.0. The input history file lives at `~/.dsh/dsh-code/history.jsonl` and is created on your first submission.
- Runtime requirements remain Node `^22.19 || >=24` and a compatible `@deepseek-ai/dsh@next` installation.
