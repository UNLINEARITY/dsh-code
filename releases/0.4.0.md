# dsh-code Release Notes - 0.4.0

## Overview

Version 0.4.0 turns the TUI into a substantially more complete terminal surface for DeepSeek Harness while making long conversations and terminal resizing predictable. The release adds full retained-history inspection, richer durable session rendering, new local workflows, and bounded viewports across every large interactive panel.

## Major features

### Complete transcript inspection

- Ctrl+O is now an exclusive selected-entry inspector instead of a simple verbose toggle. Use ←/→ to switch entries, ↑/↓ or PageUp/PageDown to scroll the complete entry, and `g`/`G` to jump to either end.
- The inspector renders the authoritative retained content rather than a preview, including long reasoning and tool results, while only the visible physical rows enter Ink's live tree.
- Persisted tool presentation data expands into readable edit/write diffs, numbered read windows, web-search source lists, fetch summaries, or a bounded raw fallback.

### Broader session intelligence

- The transcript now surfaces compaction, LLM retries, turn termination reasons, changed files, and session-title changes instead of silently dropping those durable events.
- The status footer adds average TTFT, decode throughput, context occupancy, goal progress, the session title, and sandbox overrides that diverge from the selected permission preset.
- `/help` provides a scrollable key/command/skill reference, `/export` writes the folded transcript to Markdown, and `/title` pins the current session name. Ctrl+K, Ctrl+L, and bare workspace-path completion round out the terminal editing workflow.

## Rendering and interaction improvements

### Stable long-context rendering

- Settled transcript rows flush into terminal scrollback while streaming reasoning, assistant text, live entries, todos, notices, and completion menus remain under explicit row and column budgets.
- Ctrl+O, `/help`, `/model`, approvals, questions, and plan reviews share bounded scrollable viewports, preventing long content from triggering Ink's full-terminal rewrite path.
- The composer and status footer now form one invariant four-row bottom region in every interface: the composer remains above the status line with consistent margins and alignment.

### Predictable terminal resizing

- Terminal dimensions are tracked in React so all wrapping and viewport budgets use the current size instead of stale `stdout` values.
- Resize bursts are coalesced for 75 ms, then the terminal is reset and the in-memory transcript is replayed exactly once at the settled width. This follows Codex's source-backed resize-reflow model and removes repeated whale headers, composers, status lines, and stale borders.
- The final frame preserves the draft and active inspector state; resize regressions cover both separate resizes and rapid 96→68→120-column bursts.

## Important notes

- No command, configuration, or persisted-session migration is required from 0.3.0.
- A resize reflow intentionally rebuilds terminal scrollback at the final width. The complete retained transcript remains available through Ctrl+O.
- Runtime requirements remain Node `^22.19 || >=24` and a compatible `@deepseek-ai/dsh@next` installation.
- Validation: 18 test files and 124 tests, TypeScript type checking, production build, local `cli` profile reinstall, and startup/config composition checks.
