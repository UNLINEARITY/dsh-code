# dsh-code 发布说明 - 0.4.0

## 概览

0.4.0 让 TUI 更接近 DeepSeek Harness 的完整终端界面，同时让长会话与终端缩放的行为更加可预期。本次发布加入完整保留历史检查、更多持久会话事件呈现、新的终端本地工作流，并为所有大型交互面板统一有界视口。

## 主要特性

### 完整转录检查

- Ctrl+O 从简单 verbose 开关升级为独占的单条历史检查器。←/→ 切换条目，↑/↓ 或 PageUp/PageDown 滚动条目的完整内容，`g`/`G` 跳转到两端。
- 检查器显示权威保留内容而非预览，包含长 reasoning 与工具结果；只有当前可见的物理行会进入 Ink 动态树。
- 持久化工具展示数据可以展开为清晰的 edit/write diff、带行号 read 窗口、web 搜索来源列表、fetch 摘要或有界原始内容兜底。

### 更完整的会话信息

- 转录现在会呈现 compaction、LLM 重试、turn 终止原因、改动文件与会话标题变化，不再静默丢弃这些持久事件。
- 状态栏新增平均 TTFT、解码吞吐、上下文占用、goal 进度、会话标题，以及偏离当前权限预设的 sandbox 覆盖状态。
- `/help` 提供可滚动的按键/命令/技能参考，`/export` 将折叠转录写入 Markdown，`/title` 固定当前会话名称；同时补充 Ctrl+K、Ctrl+L 与裸工作区路径补全。

## 渲染与交互改进

### 稳定的长上下文渲染

- 已完成转录行冲刷到终端 scrollback；流式 reasoning、助手正文、动态条目、todo、notice 与补全菜单均受明确的行列预算约束。
- Ctrl+O、`/help`、`/model`、审批、问题和计划评审共享有界可滚动视口，避免长内容触发 Ink 的整屏重写路径。
- 输入框与状态栏在所有界面中组成固定四行底部区域：输入框始终位于状态栏上方，并保持一致边距与水平对齐。

### 可预期的终端缩放

- React 直接跟踪终端尺寸，所有换行与视口预算都使用当前尺寸，不再读取陈旧的 `stdout` 值。
- 连续 resize 采用 75ms 尾沿合并，随后复位终端并在最终宽度只重放一次内存 transcript。该行为参考 Codex 的 source-backed resize-reflow 模型，消除重复鲸鱼头、输入框、状态栏与旧边框残影。
- 最终帧保留输入草稿和当前检查器状态；resize 回归同时覆盖独立缩放与快速 96→68→120 列连续缩放。

## 重要说明

- 从 0.3.0 升级无需迁移命令、配置或持久会话。
- resize reflow 会在最终宽度主动重建终端 scrollback；完整保留转录仍可通过 Ctrl+O 查看。
- 运行要求保持为 Node `^22.19 || >=24`，并需要兼容的 `@deepseek-ai/dsh@next`。
- 验证：18 个测试文件、124 项测试、TypeScript 类型检查、生产构建、`cli` profile 本地重装，以及启动/配置组合检查。
